### Install (Windows)
Download `Zotivity-Setup-{version}.exe` below and run it (per user, no admin rights). Check the download against `Zotivity-Setup-{version}.exe.sha256`. The installer is built by GitHub Actions from the source code of this release and is **not code-signed yet**, so Windows SmartScreen warns ("Unknown publisher"): click *More info → Run anyway*. If that option is missing (e.g. on managed PCs), right-click the file → *Properties* → tick *Unblock* → *OK*, then start it again.

Then enable Zotero's local API (Zotero → Settings → Advanced) and follow the setup checklist.
